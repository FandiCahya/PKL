# Proyek Aplikasi FitSpot (PKL)

> Sebuah aplikasi Android untuk booking gym sebagai bagian dari Praktek Kerja Lapangan (PKL).

## deskripsi Singkat

Aplikasi Booking Gym yang memungkinkan pengguna untuk memesan jadwal gym secara online. Fitur utama mencakup registrasi pengguna, pemesanan jadwal, manajemen instruktur, dan laporan booking.

---

## ✨ Fitur Utama

Berdasarkan fungsionalitas yang ada, berikut adalah beberapa fitur utama dari aplikasi ini:

* **📈 Dashboard Pengguna:** Tampilan utama yang menampilkan informasi relevan (mungkin jadwal yang akan datang atau status booking).
* **🗓️ Pemilihan Jadwal:** Pengguna dapat melihat dan memilih jadwal yang tersedia (`Choose Jadwal.png`).
* **✅ Konfirmasi Booking:** Tampilan sukses setelah pengguna berhasil memesan jadwal (`Booked Success.png`).
* **🧾 Riwayat Pesanan:** Pengguna dapat melihat daftar pesanan atau booking yang pernah dilakukan (`My Order.png`).
* **👤 Manajemen Profil:** Pengguna dapat melihat (`My Profil.png`) dan mengubah data profil mereka (`Edit Profile.png`).
* **🎨 UI/UX Lainnya:** Termasuk aset untuk ilustrasi (`Workout-amico.svg`) dan ikon (`boxing.png`).
